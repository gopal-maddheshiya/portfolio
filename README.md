## Portfolio Web Application Architecture

This portfolio repository is an enterprise-grade full-stack personal web application engineered with:

- **Server-Side Rendering & Hydration**: Powered by [TanStack Start](https://tanstack.com/start) with Nitro production build preset on Vercel.
- **Styling Architecture**: Built on [Tailwind CSS v4](https://tailwindcss.com/) with OKLCH color spaces, custom dark-mode tokens, and glassmorphic micro-surfaces.
- **Motion & Fluid Physics**: High-performance hardware-accelerated animations using [GSAP 3](https://greensock.com/gsap/), ScrollTrigger, and smooth momentum scrolling with [Lenis](https://lenis.darkroom.engineering/).
- **Cloud Backend & Realtime Sync**: Connected to [Supabase](https://supabase.com/) PostgreSQL database with WebSocket Realtime updates, multi-tab `BroadcastChannel` synchronization, and Cloud Storage for assets.
- **Administrative Content Management System (CMS)**: Integrated secure Admin Studio dashboard for dynamic content updates, media uploads, and offline JSON snapshot safeguards.

## Local Development & Setup

### Prerequisites
- Node.js (version 18.x or later)
- npm or pnpm

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/gopal-maddheshiya/portfolio.git
   cd portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Configure Environment Variables**:
   Create a `.env` file in the root directory:
   ```env
   VITE_SUPABASE_URL=https://rnchpivzlmjlvctjqitr.supabase.co
   VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
   ```

4. **Start the local development server**:
   ```bash
   npm run dev
   ```
   The application will be accessible at `http://localhost:5173`.

5. **Build for production**:
   ```bash
   npm run build
   ```
